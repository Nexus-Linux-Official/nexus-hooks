# nexus-hooks

Pacman hooks and system integration scripts for Nexus Linux.

This repository is standalone. It was split out of the former
[`NexusLinux`](https://github.com/Nexus-Linux-Official/NexusLinux) monorepo together with its
commit history.

## Build

```bash
makepkg -si
```
